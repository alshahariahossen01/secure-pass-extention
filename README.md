# secure-pass-extention
Secure Pass Vault is a full-featured browser extension designed to protect your online identity and simplify login security: 🔑 Generate &amp; manage strong, unique passwords ⚡ Auto-fill login forms quickly and securely 🧬 Unlock with biometric authentication (fingerprint/Face ID) ⏱️ Built-in TOTP 2FA for enhanced two-factor security 🔐 All data secure
